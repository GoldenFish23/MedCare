## 1. Handling Virtual Eviron
### Virtual Environ with Node 22.22.2


`nodeenv node_env --node=22.22.2` 

### Activating Environ

`node_env\Scripts\activate.bat`

### Deactivating Venv

`deactivate`

## 2. Running Dev Mode

install required packages via `npm install` with environ enabled.

- `npm run server` to run server in *Development mode*.
- `npm start` to run server in *Production mode*.

Check `package.json` for more reference. 
*Note: - Automatically an empty data_test folder is created with empty database for usage. __Utilise passcode.txt code for software activation.__*
